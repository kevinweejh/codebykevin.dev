This project presents step-by-step walkthroughs that show the anatomy of each vulnerability using simulated, static demonstrations. No setup, no Docker, no attack infrastructure.

Each vulnerability (A01–A10) walks through the same 5-step story: the normal flow, the vulnerable code, the attack, the impact, and the fix — shown from multiple perspectives (code, database, DevTools, fixed code, defense principles). 

Real-World cases are cited, exemplifying to show that even some of the largest companies are not impregnable.

Target audience: Web developers who write code daily and want to understand the shape of security vulnerabilities without needing a penetration testing background.
