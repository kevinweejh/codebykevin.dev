This project presents step-by-step walkthroughs that show the anatomy of each risk using simulated, static demonstrations. No setup, no Docker, no live model calls.

Each category (LLM01–LLM10) walks through the same 5-step story: the normal flow, the underlying vulnerable design, the attack, the impact, and the fix — shown from multiple perspectives (chat UI, server code, devtools/terminal, database/vector-index, fixed code, defense principles). Dark/light theming follows your OS setting by default, with a manual toggle to override.

Real-World cases are cited, exemplifying to show that even some of the largest companies are not impregnable.

Target audience: Developers, ML engineers and security practitioners building LLM-powered features — chatbots, RAG (Retrieval-Augmented Generation) pipelines, coding assistants, agents — who want to understand the shape of AI-specific security failures. No prior AI-security background needed.
